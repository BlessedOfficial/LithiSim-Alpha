# CMake Build Instructions (Windows + Ninja)

This project builds the C++ engine located in `engine-cpp/`.

## Prerequisites

- `cmake` installed and available in `PATH`
- `ninja` installed and available in `PATH`
- A C++ compiler toolchain (your current setup uses MinGW `g++`)

## Folder Layout

- Source directory: `engine-cpp/`
- Build directory: `engine-cpp/build/`
- Output executable: `engine-cpp/build/lithisim.exe`

## Configure (Generate Build Files)

From project root:

```powershell
cd .\engine-cpp
cmake -G Ninja -B build
```

Equivalent explicit form:

```powershell
cmake -S . -B build -G Ninja
```

## Build

From `engine-cpp`:

```powershell
cmake --build build
```

From `engine-cpp\build`:

```powershell
cmake --build .
```

## Run

From `engine-cpp`:

```powershell
.\build\lithisim.exe
```

From `engine-cpp\build`:

```powershell
.\lithisim.exe
```

## Clean Reconfigure (If Build State Gets Messy)

From `engine-cpp`:

```powershell
Remove-Item -Recurse -Force .\build
cmake -G Ninja -B build
cmake --build build
```

## Common Mistakes

- Do not run `cmake build -B build` unless `build` is your source directory.
- If you are already inside `engine-cpp\build`, use `cmake --build .`, not `cmake --build build`.
- Do not edit `engine-cpp/build/build.ninja` manually; it is generated by CMake.
